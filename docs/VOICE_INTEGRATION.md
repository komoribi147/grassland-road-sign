## 线上与本地的差别

两个静态网站播放全部固定剧情 MP3，并使用既有云端模型提供文字对话。本机 Qwen 的角色新回复语音不会随静态包上传；公网明确显示“在线回复语音尚未开通”，不请求不存在的 /api/tts，也不以其他音色替代。本地版本仍保留有声自由对话。

## 运行

- 声音工作台： http://localhost:8790/voice-preview.html
- 完整剧情： http://localhost:8790/
- 参考声线对比： http://localhost:8790/voice-candidates.html

仓库根目录双击 `启动本地配音预览.cmd`；保留窗口开启。若 8790 已由本项目运行，直接打开上述地址即可。命令行也可设置 PORT=8790 后运行 `node server/server.mjs`。普通 npm start 默认端口为 8787。

固定剧情直接播放本地 MP3，不需要等待合成。自由回复由本机 Ollama qwen2.5:14b 先回答，再由本机 Qwen3-TTS 0.6B Base 按角色参考录音生成声音。新句子仍需等待几十秒；同句回放使用缓存。晚年何秀英在声音工作台按晚年回忆情境对话，不进入行军时期剧情互动。取消、静音、后台、回看后的迟到声音均受播放器隔离。

本机为 8GB 显存环境，配音生成会临时释放空闲的对话模型显存，下一次对话自动载入。模型、Python 和缓存保留在本机 git 忽略的 node_modules 目录中。此静态包不携带模型或 Python，不代表复制到另一台设备后可直接生成自由回复。

## 文件与复做

- `voice/manifest.json`：132 处剧情位置、文本、时长、称呼变体和生成来源。
- `voice/original-recordings.json`：原 56 句文件及 SHA-256，复做时保护原件。
- `story/voice-references.json`：当前角色参考文件、准确转写和随机种子。
- `tools/complete-local-voices.mjs`：准备任务、核验参考/剧本身份、最终接入。
- `tools/complete-local-voices.py`：一次载入模型，缓存角色提示，逐句存 MP3 和断点。

批量流程：先 `npm run voices:prepare-local`，再使用 `node_modules/.qwen-local/Scripts/python.exe tools/complete-local-voices.py`，最后 `npm run voices:finalize-local`。每段生成后即存断点；同一配置恢复不会重做。参考文件、参考转写、seed、输出文件或剧本在生成期间变化会拒绝接入。不要与自由回复配音同时跑批量任务。
