# 风格样张（概念图）

这四张是用通义万相生成的**风格测试图**，不是最终成品。目的是先把"整部作品长什么样"定下来，避免九张图画完才发现方向不对。

## 四张样张

| 文件 | 内容 | 风格 |
| --- | --- | --- |
| `样张-01-序章·连环画淡彩.jpg` | 序章：雨中的沼泽草地，队伍在雾里行进 | A 连环画淡彩 |
| `样张-02-结尾路标·连环画淡彩.jpg` | 第四幕：老班长背对镜头坐在草甸上 | A 连环画淡彩 |
| `样张-03-泥沼·连环画淡彩.jpg` | 第二幕：石头陷进泥沼被拉住 | A 连环画淡彩 |
| `样张-04-序章·木刻版画.jpg` | 序章：雨中的行军队伍 | B 木刻版画 |

规格：1280 × 720（正式背景图要做成 1920 × 1080）。

## 怎么投票

在 Issue [#5](https://github.com/komoribi147/grassland-road-sign/issues/5) 下面回一句 **A** 或 **B**，或者说说你更喜欢哪张、哪里要改。全组定下来之后，就按 `docs/ART_GUIDE.md` 的提示词批量出九张正式背景。

## 已知问题（故意的，先说清楚）

- 样张-02 里老班长的**脚画糊了**——AI 画手脚容易崩，正式出图时构图要避开手脚特写。
- 样张-04（木刻）风格很带劲，但人物肢体和枪的结构有错，人多的时候更明显。如果选 B，建议只用在封面和"路标"那一张。
- 四张都是 1280×720 的草图，正式出图会做到 1920×1080 并且人工挑图。

- 模型：通义万相 `wanx2.1-t2i-turbo`
- 提示词：见 `docs/ART_GUIDE.md` 第三节
