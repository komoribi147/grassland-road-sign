# 美术需求清单

> 当前新一轮图片生产以 [VISUAL_CONSTITUTION.md](VISUAL_CONSTITUTION.md) 为准；下文保留为早期方案与素材清单。

这份清单是"照着做就能直接生效"的规格书：文件名对了，放进 `assets/`，刷新网页就能看到。

## 一、总风格（漫画为主）

一句话：**中国连环画的路子——粗黑墨线勾边、淡彩平涂、低饱和灰绿与土黄；画人，不画神。**

### 先挑一个方向

我已经出了四张样张放在 `docs/concept/`，全组看完投票选一个（在 Issue 里回一句就行）：

| 方案 | 样张 | 特点 | 适合 |
| --- | --- | --- | --- |
| **A · 连环画淡彩（推荐）** | 样张-01 / 02 / 03 | 钢笔线描 + 淡彩，线条硬朗，AI 生成最稳定，人物不容易崩，情绪细腻 | 网页背景、大屏投影 |
| **B · 木刻版画** | 样张-04 | 黑白对比强、刀味重、冲击力大 | 但 AI 画人物手脚崩得厉害，人多的时候更明显 |

两种可以混用：整体用 A，封面和"路标"那一张用 B。

### 不管选哪个，这几条都要守

- 全片基调是雨。背景里要有水汽、泥、雾、湿透的草。
- 画面里**不要出现文字、logo、水印**（AI 出图必查这一条）。
- 人物不能"高大全"：脸要糙、衣服要破、鞋要烂。红军不是戏服模特。
- **画面里人越少越好**：主要人物别超过 2 个，队伍一律用远景剪影。
  AI 画手和脚最容易崩，构图时避开手脚特写——样张-02 里老班长的脚就有点糊，属于同一类问题。

- 尺寸 **1920 × 1080**（16:9），最低不低于 1600 × 900

- 主体不要放在画面正中偏下（那里是对话框），重要内容留在上半部分和两侧

## 三、出图提示词（漫画风）

**风格底要统一**，每条提示词都带上同一段。选 A 用第一段，选 B 用第二段：

```
（A 连环画淡彩）中国连环画风格，1935年红军长征过草地，钢笔线描加淡彩，
粗黑墨线勾边，低饱和灰绿与土黄，阴雨天，横构图，画面干净，
不要任何文字、不要签名、不要印章、不要边框、不要水印
```

```
（B 木刻版画）中国木刻版画风格，黑白套色木刻，粗犷刀痕，强烈黑白对比，
1935年红军长征过草地，横构图，画面干净，
不要任何文字、不要签名、不要印章、不要边框、不要水印
```

> **实测教训**：只写"不要文字"是不够的，AI 还是会在角落加签名和印章。
> 项目里的 `tools/gen-image.mjs` 已经把 `negative_prompt`（负向提示词）设好了，
> 写上 `文字,签名,印章,落款,水印` 这类词才压得住。你在别的工具里出图，也要找找有没有这个参数。

九张图的提示词（接在风格底后面，组成完整提示词）：

1. `prologue-marsh-dusk`：`黄昏的川西高原沼泽草地，细雨，看不见边的草甸与泥水，前景湿草与泥洼倒影，远处雾气里两三个很小的背影，空旷压抑`

3. `act2-morning-fog`：`清晨大雾，五步外看不见人，一列小小的人影踩着前面的脚印前进，最前面一根探路的木棍，雾气占画面大半`
4. `act2-bog`：`黑色泥沼特写，翻起的泥浆与浑浊水花，一根伸进去的木棍，一只手抓住木棍，紧张的救援瞬间，画面动荡`
5. `act3-rain-markers`：`大雨中的沼泽草地，泥地里每隔几十步插着一根木棍，上面绑着布条和旧草鞋，远处一棵歪脖子树，分不清方向`
6. `act3-night-high-ground`：`夜晚草地上一小块干燥高地，裹着油布躺着的伤员，几个人挤在一起，天边一丝微光，安静压抑`
7. `act4-dawn-river`：`雨后清晨，草地尽头一条河在晨光中发亮，天边一道亮光，湿漉漉的草甸，几只飞起来的鸟`
8. `act4-signpost`：`一个穿着破旧军装的年长士兵背对镜头坐在草甸上，面朝来路，手里一根绑着红布条的木棍，清晨薄雾，背影静默如路标，画面安静克制，注意脚部不要画糊`
9. `epilogue-today`：`今天的川西高原草地，晴朗，草甸上一条小路，路边一座纪念碑，几个戴红领巾的小学生背影，温暖明亮，和前面的雨天形成对比`

生成后**必须人工过一遍眼**，按这个顺序检查：

1. 有没有出现文字、字母、印章、签名（AI 最爱偷偷加）
2. 人手人脚有没有崩（六指、融合、像肉块）
3. 有没有现代物件（拉链、塑料、眼镜、不对的水壶）
4. 衣服有没有年代感（灰军装、八角帽、草鞋、绑腿）

### 怎么出图

- **先看这条纪律**：出图**优先用免费额度**——即梦、通义万相网页版、豆包这类工具每天都有免费次数，够我们做九张图。
  项目里那个脚本走的是**付费接口**，用它之前先问组长，别随手跑。

- **要批量出、且组长同意花钱时**：在根目录的 `.env` 里填上 `DASHSCOPE_API_KEY`（阿里云百炼的 Key）之后：

  ```
  node tools/gen-image.mjs "把风格底和场景提示词拼在一起" assets/bg/prologue-marsh-dusk.jpg 1920*1080
  ```

  约 10 秒一张，一张几毛钱。注意这个模型的尺寸上限是 **1440×810**，写 1920×1080 会直接报错。
- **用在线工具出**：即梦、可灵、通义万相、豆包都可以，把上面的提示词整段粘进去。
- **手绘 / 约稿**：有美术同学愿意画，就照着 `docs/concept/` 里选定那张的风格画，统一性最好。

## 六、音频清单

放在 `assets/audio/`，**文件名必须完全一致**，格式 mp3：

| 文件名 | 内容 | 说明 |
| --- | --- | --- |
| `rain.mp3` | 雨声 | 循环，全片主要环境音，可用免费素材站的雨声 |
| `sfx-splash.mp3` | 泥水溅起 | 石头陷进泥沼时播放 |
| `sfx-bugle.mp3` | 军号 | 第四幕石头吹号 |
| `sfx-shout.mp3` | 远处有人喊"跟上" | 序章结尾，队伍在雾里喊话；声音要远、要糊 |

> 代码现在只挂了这四个，后面要加"风声""脚步""歌声"，在剧本 JSON 里写一行 `{ "t": "sfx", "name": "wind" }` 就生效，文件名按 `sfx-<name>.mp3`。

音频来源建议：Freesound、爱给网、站长素材（注意授权，选可商用/署名即可的）。

## 七、三条路怎么选

| 方案 | 成本 | 适合 |
| --- | --- | --- |
| AI 生成 + 人工挑选修图 | 0 元，约 10 分钟/张 | 时间紧、没画手，**推荐先用这条路把 9 张铺满** |
| 找同学手绘 / 版画风 | 一顿饭～友情价 | 有美术专业的朋友，风格最统一、最像"作品" |
| 约稿 | 50～300 元/张 | 需要赶时间且追求统一质量 |

不管走哪条路：**先出 1 张样图给全组看**，定下风格之后再批量做，否则容易九张风格各异。

## 八、怎么验收

1. 把图按文件名放进 `assets/bg/`。
2. 在项目目录运行 `node tools/check-story.mjs`，如果还提示"缺少背景图"，说明文件名不对。
3. 运行 `node server/server.mjs` 打开网页，走到对应场景看一眼。
4. 舒服了就提 PR，标题写 `art: 上传 xx 背景图`。
