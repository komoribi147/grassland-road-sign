# 美术需求清单

这份清单是"照着做就能直接生效"的规格书：文件名对了，放进 `assets/`，刷新网页就能看到。

## 一、总风格

一句话：**阴雨、低饱和、灰绿与土黄，电影感，不画英雄，画人。**

- 参考气质：纪实摄影、老照片、版画、水墨留白都可以，但**不要**热血动漫风、不要 3D 游戏风、不要饱和度很高的插画。
- 全片基调是雨。背景里要有水汽、泥、雾、湿透的草。
- 画面里**不要出现文字、logo、水印**。
- 人物不能"高大全"：脸要糙、衣服要破、鞋要烂。红军不是戏服模特。

- 尺寸 **1920 × 1080**（16:9），最低不低于 1600 × 900

- 主体不要放在画面正中偏下（那里是对话框），重要内容留在上半部分和两侧

## 三、出图提示词模板（用 AI 生成）

可以直接复制到即梦、可灵、通义万相、豆包、Midjourney 等工具里。**风格词要统一**，建议每次都用同一段"风格底"：

```
风格底：1935年中国工农红军长征过草地，纪实摄影质感，阴雨天，低饱和灰绿色调，
电影感构图，胶片颗粒，无文字，无现代元素
```

生成后请人工挑图：**看人物有没有六根手指、衣服有没有现代拉链、有没有出现文字**。AI 图一定要过一遍眼。

## 四、人物立绘（下一步任务，暂未接入代码）

> 提示：AI 每次回话都会带一个情绪（mood），取值只有七个：**警惕、缓和、疲惫、难过、坚定、好奇、平静**。
> 画立绘时按这七个情绪画，将来接进代码就能自动切表情。下表是三个人各自需要的三个。

三个角色各需要 3 种表情，透明背景 PNG，竖构图约 **900 × 1400**：

| 角色 | 文件名 | 状态 |
| --- | --- | --- |
| 老班长 李长河 | `char/li-changhe-wary.png` / `-soft.png` / `-tired.png` | 警惕 / 缓和 / 疲惫 |
| 石头 | `char/shitou-scared.png` / `-curious.png` / `-smile.png` | 害怕 / 好奇 / 笑（露缺牙） |
| 何大姐 | `char/he-xiuying-calm.png` / `-firm.png` / `-sad.png` | 平静 / 坚定 / 难过 |

形象要点（防止画错）：

- 老班长：52 岁，脸像干裂的树皮，胡子茬上挂雨珠，腰间挂破炊帚，背一口黑锅。
- 石头：16 岁，瘦小，嘴唇发白，军号不离手，**缺一颗门牙**。
- 何大姐：25 岁，个子不高，脸被晒得黑红，背一个旧药箱，穿自己做的布鞋。

## 七、三条路怎么选

| 方案 | 成本 | 适合 |
| --- | --- | --- |
| AI 生成 + 人工挑选修图 | 0 元，约 10 分钟/张 | 时间紧、没画手，**推荐先用这条路把 9 张铺满** |
| 找同学手绘 / 版画风 | 一顿饭～友情价 | 有美术专业的朋友，风格最统一、最像"作品" |
| 约稿 | 50～300 元/张 | 需要赶时间且追求统一质量 |

不管走哪条路：**先出 1 张样图给全组看**，定下风格之后再批量做，否则容易九张风格各异。

## 八、怎么验收

1. 把图按文件名放进 `assets/bg/`。
2. 在项目目录运行 `node tools/check-story.mjs`，如果还提示"缺少背景图"，说明文件名不对。
3. 运行 `node server/server.mjs` 打开网页，走到对应场景看一眼。
4. 舒服了就提 PR，标题写 `art: 上传 xx 背景图`。
