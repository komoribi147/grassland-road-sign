# 参赛方案（AI + 教育）

## 一、作品是什么

《草地上的路标》是一件**沉浸式历史叙事作品**：玩家在松潘草地的泥水里醒来，说不清自己的番号，跟着老班长、石头、何大姐往外走。

不是"看一段历史"，是"在一个历史情境里做几十次选择，然后发现：他们记住的是你说过的话"。

## 二、AI 在哪里、教育在哪里

| 传统做法 | 我们的做法 | 教育价值 |
| --- | --- | --- |
| 给玩家几个选项，选完继续 | 主角**没有任何预设台词**：所有要说的话都自己打；随时还能点「开口说话」找在场的人聊 | 学生必须真的组织语言、真的共情，才能接得上话 |
| 所有 NPC 共用一个模型、一份记忆 | **三个 NPC 三个独立的大模型**：各有人设、各有模型参数（甚至各用各的账号）、各有各的对话记忆 | 同一句话对不同的人说，反应不一样——这就是"理解他人" |
| 只有一个结局 | 信任值从 0 走到 100，称呼从"你"到"同志"到"文书" | 把"信任"变成可感知的量，而不是一句口号 |
| 看完就完了 | 8 张史料卡 + 结尾学习报告 | 从故事回到史实，给延伸阅读的抓手 |

技术实现：

- **前端**：纯静态网页（HTML / CSS / 原生 JS），零依赖、可离线、能跑在手机上
- **剧情引擎**：JSON 驱动的状态机，支持分支、条件、信任值、存档
- **AI**：每个 NPC 一份独立人格提示词（人设 + 当前情境 + 信任值 + 只有他记得的对话历史）；NPC 除了回话，还要自己判断"玩家这句话让我对他的信任变化多少"，把信任值交还给角色本身
- **模型**：讯飞星火（OpenAI 兼容接口），`server/ai-config.json` 支持逐角色配置模型、温度和 API 账号；没网时自动降级为剧本兜底台词
- **教育数据**：结束后生成学习报告（选择数、自由表达字数、解锁史料卡、遇到的人物）

## 三、现场演示脚本（4 分钟）

1. **0:00** 打开首页，念标题页那句话："一个不记得自己番号的人，跟着一支队伍往外走。"
2. **0:30** 开始游戏，走到老班长盘问"你是哪个连的"——不点选项，**现场请评委或观众说一句**，让玩家把这句话打进去，看 NPC 如何回应。
3. **1:30** 走到第二幕泥沼救援，连点三下救石头，强调"这一段必须动手"。
4. **2:30** 跳到第三幕夜话，展示称呼变化：左下角显示"他们现在叫你同志/文书"。
5. **3:00** 打开史料卡，讲一张（推荐"长征中的女红军"或"班佑河与今天的碑"）。
6. **3:30** 直接播到结尾，让"他让我记住。我记了一辈子。"说完，停 2 秒，再说收尾句。

> 备用：`#auto` 自动演示 + 录屏文件，防止现场网络或设备出问题。

## 六、可能会被问到的问题

**Q：AI 会不会乱说话、说错历史？**
A：人设提示词里写死了"不使用 1949 年之后的词汇""不喊口号""史实由剧本承载"；AI 只负责在既有情境里接话，不负责讲史实。史实全部由人工撰写的史料卡承担。

**Q：为什么非要三个模型，一个不够吗？**
A：一个模型当然也能跑。分成三个是设计需要：老班长话少要稳（温度调低），石头是十六岁的孩子要跳（温度调高，用轻量模型就够），何大姐要克制。分开之后三人的语气和判断标准互不污染，记忆也各自独立——你在石头面前说的悄悄话，老班长不会知道。

**Q：没有网络怎么办？**
A：网页本身离线可跑，NPC 用剧本兜底台词，完整故事不受影响。

**Q：这是"游戏"还是"教育产品"？**
A：是叙事作品。教育性体现在体验之后：史料卡与学习报告把玩家拉回史实，并留出继续了解的问题。

**Q：和普通文字冒险游戏的区别？**
A：① NPC 会记住玩家说过的话并据此改变称呼；② 展示的是"普通人如何互相把彼此带出绝境"，不是英雄叙事；③ 有可量化的学习产出。

## 七、风险与备案

| 风险 | 备案 |
| --- | --- |
| 大模型接口被限流/欠费 | 兜底台词自动接管，演示照常 |

| 队友不熟悉 GitHub 把 main 改坏 | 开启分支保护，必须 PR + 1 人审核 |
