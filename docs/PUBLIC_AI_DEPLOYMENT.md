## 填写密钥并部署

1. 将 `server/.env.cloud.example` 复制为根目录 `.env.cloud`。这个文件已加入 Git 忽略列表，不影响现有本地 `.env`。
2. 填写所选模型对应的 `AI_API_KEY`、`AI_BASE_URL`、`AI_MODEL`。讯飞 HTTP 接口需要对应版本的 APIPassword；使用 DeepSeek 时需同时改地址与模型名。
3. 运行 `npm run deploy:ai`。脚本更新现有云函数，只把密钥写入临时私有请求文件和云函数环境；不会把密钥写进可提交的 `cloudbaserc.json`、网站、压缩包或系统进程参数。临时请求文件会清理。
4. 运行 `npm run check:public-ai -- --live`，检查主线与自由提问接口。该步骤会向真实模型发送少量测试问题。
5. 从公开网站向三名角色各问一句，检查真实回答、记忆隔离、失败提示，以及多人访问。

仅健康检查显示已配置，不足以证明模型密钥有效。最终必须通过真实回答与网页请求验证。

后续更新函数请使用 `npm run deploy:ai`，避免直接使用不含密钥的公共配置覆盖云端环境变量。现有服务限流仍是按实例、按 IP 的基础限制；正式扩大访问规模前，应结合模型平台额度和网关能力进一步约束总调用量。
