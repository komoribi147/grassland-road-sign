# 走过草地以后

故事结束后的个人回望页。教育体验通过人物处境、真实对话、选择与自主感受展开；这里不设置题目、评分或完成任务的要求。

## 页面内容

- 沿用故事结尾原句和今天草地的画面。
- 从本次存档的角色记忆和对话历史摘录三位同行者的原话。何大姐与其晚年形象合并为同一人；没有实际对话时不编造相遇。
- 留下玩家在剧情中说过的话及做过的选择，不把预选项回答描述成完全由玩家原创的文字。
- 可以自愿选择一位同行者的一句话，再写一句属于自己的话；也可以留白。
- “故事之外的历史”默认折叠，只呈现本次解锁的史料正文与来源，不添加问答。

## 保存与呈现

留言和留住的那句话写入当前游戏存档；返回首页后可通过“继续”再次打开。开始全新故事仍会建立新存档，如希望保留这次回望，可先点击“保存回望”下载纯文本。

下载包含对话摘记、玩家原话、选择、留言及史料来源。页面与下载都不展示信任值、字数、对话轮数等成绩化统计，不根据这些记录判断价值观或学习水平。

角色原话可能来自剧本或实际发生过的 AI 对话。回望页本身不生成或评价玩家的情绪。所有原话通过文本节点或文本框呈现。

实现位于 `js/reflection-report.js`（记录与导出）和 `js/reflection-view.js`（页面）；结尾由现有剧情引擎接入。静态网站与单文件打包均包含相关模块。
