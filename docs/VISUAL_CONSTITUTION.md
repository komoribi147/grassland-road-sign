# 《草地上的路标》视觉宪法（2026-10-18）

本文件是新一轮图片生产的统一标准。原始生成图保存在 `output/visual-masters/`，本地剧情使用的候选图保存在 `assets/stills/`；用户目视验收前不发布。

## 本地制作状态

- 正式剧情的 89 个画面节点及背景、选项等合计 98 次图片使用，现对应 98 张不同的纪实镜头文件；逐镜头清单见 `docs/SHOT_INVENTORY.md`。旧六格分镜与旧背景不再被剧情引用，也不进入静态发布包。
- 人物立绘保留在仓库，剧情暂不加载，静态发布包也不包含。
- 播放时每张独立画面切入有短暂淡入，再做幅度克制的双向慢推拉。雨幕沿用剧情环境音状态，薄雾只在雨地、雾路、河边和路标背景缓慢漂移。系统“减少动态效果”会关闭镜头、雨丝与薄雾运动。泥沼按住协力的完整交互仍在独立样张 `rescue-demo.html`。
- 图片是独立剧情镜头，不宣称为动作逐帧还原。替换镜头时须保持剧情时序和人物、衣物、道具连续性；原候选图保存在 `output/visual-masters/single-frames/`，不覆盖原件。

## 唯一主风格

电影级写实历史概念设定＋低饱和雨雾纪实胶片感＋第一人称交互轻 HUD。画面像真实历史电影剧照：湿冷、克制、有人在场的重量；不做宣传海报、游戏角色卡、二次元或赛博界面。

- **色板**：灰绿 `#5A6653`、泥褐 `#6B5A45`、湿黑 `#2B2A26`、冷灰 `#8A9088`；只有剧情中的红布可用较高饱和的 `#B33A2B`。红布出场前的画面不提前出现鲜红色。
- **光线**：阴天漫射光、冷雨、薄雾；黎明只略暖。低对比但层次清楚，不用舞台聚光、强逆光或金色日出。
- **材质**：湿泥、烂草、粗布、磨损草鞋、黑铁锅、氧化军号、旧药箱、绷带。材质应通过形状与受光来辨认，不靠全画面颗粒堆砌。
- **镜头**：场景与交互特写 16:9，低机位、近地面和第一人称视角优先；人物母版 1:1 半身透明底，道具另做透明底。网页背景的重要动作保留在中央约 80% 安全区，给对白预留安静区域。
- **质感控制**：只允许极轻的统一胶片颗粒；天空、水面、雾保持干净。脸、手、军装结构和关键道具清晰，不出现砂砾噪点、重复草叶、油画碎笔触或塑料 CG 表面。
- **UI**：半透明雨滴感与细线，低饱和。对话选项、信任值、记忆标签和“历史记忆档案”是界面核心；不画机器人或霓虹科幻元素。UI 由网页层实现，不烘焙进场景图片。

## 剧情连续性

2026-10-18 用户选定的视觉方向参考为 [泥沼拉人首选参考](../../output/visual-masters/05-泥沼拉人-用户首选参考.png)，原话为“这张图片最符合预期”。后续优先沿用其真实紧张的人物表情、三人协作关系、低机位斜向构图、低饱和雨雾和湿泥材质；这项选择用于画面方向，不替代逐张的历史、人体与受力检查。对应的新候选图已接入本地剧情，仍待用户目视验收。

依据 `story/scenes/*.json` 修订剧本：李长河 52 岁，疲惫瘦削，背黑锅、带炊帚；石头 16 岁，身形瘦小，门牙缺一颗，带旧军号；何秀英 25 岁，日晒黑红的脸、旧药箱、被雨淋花的伤员名册。人物不美化，服装和物件须前后连贯。

**人物面貌与场景核对**：1935 年草地叙事中的人物须呈现自然可信的中国面孔，保持同一角色的年龄、肤色、发型和神态连续；避免西方面孔、时装模特式五官与妆容。检查背景是否误生马匹、帐篷、营火、现代塑料等剧本外物件；潮湿油布应有粗布织纹和实际受力，不呈塑料薄膜质感。今天的草地中的小学生也须符合中国当地真实日常形象。

- 序章醒来时没有红布路标；老班长先用**普通探路木棍**与主角保持戒备。
- 序章老班长把右脚草鞋让给主角，此后他的右脚光着；后来左脚那只也磨断，终章两脚均光着。
- 泥沼边第一根红布木棍留给后队；第三幕石头从军号取下另一条红布系到老班长探路棍上；终章是第二根木棍。不要混成同一物件。
- 老班长最后坐在来路旁面对雾，红布木棍在身边。画面克制，不摆英雄姿势。

## 固定提示词结构

每张按“剧本时间与动作 → 人物和道具准确细节 → 镜头与网页留白 → 统一色板和漫射光 → 材质与轻颗粒 → 排除项”编写。人物层用母版人物做参考；新场景用已批准母版做画风参考。生成时不要把文字、UI 或解释标签直接画进图里。

**固定排除项**：文字、水印、标志、现代物件、二次元、宣传海报姿势、戏服质感、塑料 CG、霓虹、高饱和背景、浓重胶片噪点、重复草丛、额外手指、畸形肢体、错误的鞋与红布时间线。

## 审核

先看剧情与人物道具，再看构图、尺寸、色板和噪点。六张母版经审核后才能作为批量派生的参考；每张生成图保留对应提示词和版本号。统一调色只微调色温与明度，不叠加明显颗粒滤镜。
