# 分镜制作说明

当前剧情使用 `assets/storyboards/sheet-01.jpg` 至 `sheet-16.jpg`，另有一张尾声独立画面 `epilogue-scarves.jpg`。六格分镜用 `visual.sheet` 和 0～5 的 `visual.panel` 指向单格，独立画面用 `visual.src` 指向整张图。93 个画面或动作节点各占一个独立画面，不复用。页面只显示画面，`description` 留给编剧、美术和无障碍说明。

| 分镜图 | 剧情范围 |
| --- | --- |
| 01～03 | 序章：泥水醒来、站起、鞋与出发 |
| 04～05 | 第一幕：分汤、草根、营地 |
| 06～09 | 第二幕：泥沼救援、救治、插路标 |
| 09～12 | 第三幕：走散、对话、饮水与记忆 |
| 12～14 | 第四幕：老班长、草鞋、路标 |
| 14～15、独立画面 | 尾声：纪念碑、正向佩戴红领巾的学生与今天 |
| 16 | 三处动作选择的两种结果 |

后续新增画面的提示词基调：1935 年松潘草地，灰绿雨雾、泥水、旧布与磨损物件；手绘历史连环画，克制的水墨和铅笔质感，人物衣着与道具前后一致。镜头尽量从玩家眼睛出发，必要时让自己的手、膝盖或脚出现在画面边缘。每格表现一个明确动作或可见结果，连续格之间保持动作方向一致；不要添加文字、对白框、标题或水印。现代纪念碑场景另用今天的服装和光线，但保持连环画笔触。

添加画面时，先给每个动作分配未使用的独立格子，再在对应剧本步骤加 `visual`；最后运行 `node tools/check-story.mjs`，检查图片存在且没有格子重复使用。
