## D · 配乐（5 条，都在等同一个动机）

**音乐组的第一件事不是作曲，是写动机**：四个下行音，口琴能吹、钢琴能按的那种。
写出来之后下面五条全是它的变奏——顺带解决了"六段互不相干的 BGM 没人记得住"的问题。

| ID | 位置 | 音乐方案 | 音量 |
| --- | --- | --- | --- |
| BGM-01 | 序章 27–30 | 动机初次露头：口琴，混在雨里，几乎听不出旋律 | 0.15 |
| BGM-02 | 第一幕 39 | 动机主题：口琴独奏（同时就是旁白里那句「八月继续向前进」） | 0.25 |
| BGM-03 | 第三幕 32–34 | 动机慢速变奏：弦乐或钢琴 | 0.20 |
| BGM-04 | 第四幕 6–8 | 动机全奏（全片唯一一次），第 8 步之后撤掉 | 0.25 → 0 |
| BGM-05 | 尾声 5–8 | 动机明亮变奏，童声或钢琴 | 0.22 |

文件命名 `bgm-<名字>.mp3`；剧情里用 `{ "t": "bgm", "name": "…", "fadeIn": 3, "fadeOut": 4 }` 触发。
