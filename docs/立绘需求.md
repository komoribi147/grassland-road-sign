# 人物立绘：怎么弄到手

代码这边**已经接好了**：图片按下面的文件名放进 `assets/char/`，刷新网页就出现在对话框左侧。
现在一张都还没有（跑 `node tools/check-story.mjs` 会显示「人物立绘：0/9 张」）。

## 一、需要什么

三个角色 × 三个表情 = **9 张**，竖构图、透明背景 PNG。

| 角色 | 文件名（放 `assets/char/`） | 表情 |
| --- | --- | --- |
| 老班长 李长河 | `li-changhe-wary.png` / `-soft.png` / `-tired.png` | 警惕 / 缓和 / 疲惫 |
| 石头 | `shitou-scared.png` / `-curious.png` / `-smile.png` | 害怕 / 好奇 / 笑（露缺牙） |
| 何大姐 何秀英 | `he-xiuying-calm.png` / `-firm.png` / `-sad.png` | 平静 / 坚定 / 难过 |

规格：

- **画到腰就够了（半身像）**。这一条很关键：AI 画手和脚最容易崩，半身像直接把风险避开
- 900 × 1400 左右（最低 600 × 1000），竖构图，人物居中，脸朝左侧或正面
- 透明背景 PNG
- 画面里不要文字、签名、印章

## 二、三条路，按你的情况选

| 路子 | 成本 | 适合 |
| --- | --- | --- |
| **① 免费 AI 工具自己生成（推荐）** | 0 元，约 2 小时 | 没画手、赶时间。即梦 / 通义万相网页版每天都有免费额度 |
| ② 找会画画的同学 | 一顿饭 | 有美术朋友，风格最统一、最像"作品" |
| ③ 约稿 | 50~300 元/张 | 追求质量且预算够 |

> ⚠️ **不要用付费 API 出图。** 即梦、通义万相的**网页版**每天送免费次数，够用；
> 接口调用（我们项目里那个脚本）是要花钱的，用之前先问组长。

## 三、用 AI 生成：完整步骤

### 第 1 步：挑一个工具，就一直在里面做

推荐**即梦 AI**（`jimeng.jianying.com`，字节的，中文理解好，有"参考图"功能）。
备选：通义万相网页版、豆包。

**别在不同工具之间来回跳**——不同工具的风格差很远，换来换去九张脸就对不上了。

### 第 2 步：先做一张"基准图"

以老班长为例，把下面这段**整段**粘进去：

```
中国连环画风格，1935年红军长征过草地，钢笔线描加淡彩，粗黑墨线勾边，低饱和灰绿与土黄，
一个五十二岁的中国老兵，瘦，脸像干裂的树皮，深深的皱纹，胡子茬上挂着雨珠，
破旧的灰蓝色红军军装，八角帽，腰上别着一把破炊帚，背着一口黑锅，
表情警惕，眼神锐利地盯着人，半身像，双手在画面外，正面偏左，背景纯色
```

负向提示词（如果有这个框，粘进去）：
```
文字,签名,印章,落款,水印,边框,现代物件,眼镜,拉链,六根手指,畸形的手,多个人物,全身
```

一次生成 4 张，挑一张最好的。**挑中的那张就是老班长的"基准脸"**，存下来。

### 第 3 步：用基准图做表情变体

在即梦里用**参考图 / 图生图**功能，把刚才那张基准图传进去（相似度调到 0.6~0.7），
提示词**一个字都不用改**，只把表情那句换掉：

| 要哪个表情 | 把"表情警惕，眼神锐利地盯着人"换成 |
| --- | --- |
| 缓和 | `表情缓和，嘴角微微放松，眼神还是沉的` |
| 疲惫 | `表情疲惫，眼皮下垂，硬撑着` |

这样出来的三张，脸是同一张。

### 第 4 步：另外两个角色

换角色卡重复第 2~3 步。另外两张角色卡（表情词同样按上表替换）：

**石头**
```
中国连环画风格，1935年红军长征过草地，钢笔线描加淡彩，粗黑墨线勾边，低饱和灰绿与土黄，
一个十六岁的中国少年红军，瘦小，大眼睛，嘴唇发白，缺了一颗门牙，
旧而偏大的灰军装，八角帽有点大，怀里抱着一把军号，
表情好奇，歪着头，眼睛发亮，半身像，双手在画面外，正面偏左，背景纯色
```
（害怕 → `表情害怕，眼睛瞪大，缩着肩膀`；笑 → `咧嘴笑，露出缺掉的那颗门牙`）

**何大姐**
```
中国连环画风格，1935年红军长征过草地，钢笔线描加淡彩，粗黑墨线勾边，低饱和灰绿与土黄，
一个二十五岁的中国女红军卫生员，个子不高，脸被晒得黑红，头发挽在帽子里，
洗得发白的灰军装，背着一个旧药箱，
表情平静，眼神冷静温和，半身像，双手在画面外，正面偏左，背景纯色
```
（坚定 → `表情坚定，下颌收着，直视前方`；难过 → `眼睛发红但没哭，抿着嘴`）

### 第 5 步：抠成透明背景

- 即梦生成时可以选**透明背景**，直接就是 PNG
- 如果没有：生成时把背景写成"纯色背景"，然后用免费在线抠图——remove.bg（有免费额度）、稿定抠图、改图鸭
- 抠完检查一下**边缘有没有白边**，有白边就用工具里的"边缘羽化"修一下

### 第 6 步：放进去验收

1. 按上表的**文件名**（一个字都不能差）放进 `assets/char/`
2. 跑 `node tools/check-story.mjs`，看是不是变成了「人物立绘：3/9 张」
3. 双击 `2-打开本地预览.bat`，走到老班长说话的地方——他应该出现在**对话框左侧**
4. 提 PR，标题写 `art: 上传老班长立绘三张`

## 四、表情是怎么自动切换的

不用你管代码，两处都会自动切：

- **剧本里写死的**：台词步骤加一个 `"mood": "疲惫"`
- **AI 判断的**：接上大模型后，NPC 每次回话都会带一个情绪，立绘跟着变

中文情绪和文件名的对照（剧本里写中文就行）：

| 剧本里写 | 对应文件后缀 |
| --- | --- |
| 警惕 | `-wary` |
| 缓和 | `-soft` |
| 疲惫 | `-tired` |
| 害怕 | `-scared` |
| 好奇 | `-curious` |
| 笑 | `-smile` |
| 平静 | `-calm` |
| 坚定 | `-firm` |
| 难过 | `-sad` |

万一某个表情没画，代码会**自动退回** `assets/char/角色名.png`，再没有就干脆不显示——
不会报错，也不会留个空框。所以你可以**一张一张慢慢补**。

## 五、搞不出来怎么办（不算丢人）

1. **不做也能完整演示**。现在的版本已经没有立绘也能从头玩到尾，音效、背景、剧情都齐。
2. **只做 3 张**（每个角色一张默认表情），代码会自动拿它兜底，效果已经够用。
3. **做剪影 / 背影版**：黑灰剪影 + 粗描边，比画脸容易十倍，而且正合我们"不画英雄、画人"的调子。
4. 先做**老班长一个人**，他台词最多、戏最重，性价比最高。
