# 人物立绘

网站使用四张透明背景半身立绘，放在 `assets/char/`：

| 人物 | 文件 |
| --- | --- |
| 老班长李长河 | `li-changhe.png` |
| 司号员石头 | `shitou.png` |
| 护理员何秀英 | `he-xiuying.png` |
| 晚年的何秀英 | `he-xiuying-old.png` |

四张立绘已经接入剧情。它们以 `assets/storyboards/` 中的对应人物为形象参考：老班长带黑锅与探路木棍，石头抱军号，何秀英带医药挎包，晚年何秀英延续年轻时的面部特征。统一使用克制的历史连环画笔触、灰色旧布纹理和透明背景。页面会按人物编号加载同一张立绘，让人物在不同情绪和章节中保持同一张脸。

替换立绘时保留对应文件名、透明背景和人物全貌边界，然后运行 `node tools/check-story.mjs`。网页和单文件版都会自动使用新图。
