# 草地上的路标

一件以长征过草地为背景的**第一人称沉浸式叙事网页作品**：我从泥水里醒来，记不起自己的番号，跟着老班长、石头、何大姐往外走。场景与动作由画面呈现，人物会记住我说过的话，并据此改变对我的称呼。

> 河南工业大学 · 讯飞杯参赛作品（AI + 教育方向）

> **第一次来？先看 [docs/START_HERE.md](docs/START_HERE.md)**——三条路，看你想做哪件事，不用先学编程。

在线预览：[中国大陆测试站（腾讯云 CloudBase）](https://grassland-road-sign-d8bdfce86570-1453404640.tcloudbaseapp.com/) · [GitHub Pages](https://komoribi147.github.io/grassland-road-sign/)。CloudBase 免费体验版的默认域名仅供开发测试，打开时可能出现腾讯云的访问提示。

## 现在就能跑

需要本机有 Node.js（本项目零依赖，不用装任何东西）。

```bash
node server/server.mjs
```

然后浏览器打开 <http://localhost:8787>。

要**发给别人看**（微信、U 盘、没网的现场）：双击 `3-生成单文件版.bat`，会生成一个
`草地上的路标-单文件版.html`，那一个文件双击就能玩，不需要服务器、不需要联网。

> ⚠️ **不要**直接双击 `index.html`。浏览器不允许本地网页（file://）加载剧情数据和脚本，
> 打开只会是一个点不动的封面。要本地跑就用上面的服务器，或者用单文件版。

想让 NPC 真正"活"起来（预选项回答由大模型即兴回应）：把 `server/.env.example` 复制成项目根目录的 `.env`，填上讯飞开放平台的 APIPassword 和模型名，然后重新运行上面的命令。详见 [docs/DEPLOY.md](docs/DEPLOY.md)。

想看自动演示（展台播放、录屏）：打开 <http://localhost:8787/#auto>，`#auto60` 是快放。

想开口说话（Chrome / Edge）：剧情弹选项时，可以点选项，也可以**按住顶栏的麦克风**说自己想说的话；「开口说话」面板里同样支持。第一次用需要允许浏览器使用麦克风。

## 四个亮点

1. **画面代替旁白**：16 张连环画分镜加 1 张独立画面承载 89 个独立画面节点。醒来、走路、救援、插路标及动作选项都有对应画面，玩家从自己的视角经历故事。
2. **主角的台词是一句一句选出来的**：NPC 问话时，会弹出两三句候选回答，点哪句就说哪句。想自己说也行——按住顶栏的麦克风说（Chrome / Edge）。想主动找谁聊，随时点顶部的「开口说话」。
3. **三个 NPC 各有自己的记忆**：老班长、石头、何大姐各有独立人设、模型参数和对话记忆。连上大模型时，信任值由 NPC 判断；没连上时，剧本台词和预设信任值保证剧情完整。
4. **信任值、史料卡与学习报告**：称呼从"你"变为"同志"、"文书"；体验中解锁 8 张史料卡，结束时生成学习报告。

## 目录结构

```
index.html            页面
css/                  样式
js/                   引擎（剧情播放、信任值、AI 对话、存档）
story/                剧本数据 ← 编剧改这里
  manifest.json       章节清单
  characters.json     人物设定（也用来生成大模型的人设提示词）
  lore.json           史料卡
  scenes/*.json       每一幕的剧情
assets/               美术与音频资源 ← 美术交这里
  storyboards/        六格分镜图，每格对应一个画面或动作
server/server.mjs     本地服务器 + AI 转发（零依赖）
server/ai-config.json 每个 NPC 用哪个模型、哪个账号 ← AI 负责人改这里
tools/check-story.mjs 剧本数据自检
docs/                 协作、美术、部署、参赛文档
```

## 每次改完先自检

```bash
node tools/check-story.mjs
npm test
```

`check-story.mjs` 会检查跳转、人物名、史料卡编号、缺图提示，还会列出"需要团队定稿的补写内容"。
`npm test` 跑剧情引擎的回归测试（回看的画面归属：翻到的、往回跳的、往后跳的必须是同一张）。

剧本一改，玩家存档里那些"哪一句配哪张画面"的记录会自动作废重记（按内容的指纹判断），
免得新剧本的句子配上旧剧本的画面。

剧情数据（42KB）每次打开都强制取最新的一份（地址带本次会话的随机戳，绕开浏览器与 CDN 缓存），
避免刚部署完还玩到上一版剧本；取不到时才退回上次存在浏览器里的副本。
