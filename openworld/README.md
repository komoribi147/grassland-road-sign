# 开放世界原型

**这是技术原型，不是成品。** 地块和人物都是色块占位，美术还没做——先证明"在草地上自由走、自由说话、会迷路、会陷泥、要给后面的人插路标"这套玩法成立。

## 怎么打开

先双击项目根目录的 `2-打开本地预览.bat`，然后浏览器打开：

**http://localhost:8787/openworld/**

## 怎么玩

- **走**：WASD / 方向键，或者点地图上想去的地方
- **说话**：走到人旁边，点跳出来的按钮（或按 E）
- **插路标**：站在能走的地方按 E
- **小心**：深色泥地会陷进去，别慌，等同志来拉你
- **目标**：往东走，找到班佑河

## 已经跑通的机制

| 机制 | 说明 |
| --- | --- |
| 地图 | 64×48 格，固定种子生成，五种地形 |
| 雾 | 只看得清身边六格；走过的地方留下暗色记忆（对应剧本"五步外看不见人"） |
| 陷泥 + 救援 | 踩进泥沼会被困住，附近的同伴会来拉你，信任 +5 |
| 插路标 | 全片的主题变成了玩法；插得越多，指南针越准 |
| 自由对话 | 和主线共用 `/api/npc`，没接大模型时用剧本兜底台词 |
| 跟随 | 跟谁说过话，他就开始跟着你 |

## 给程序同学的说明

- 全部逻辑在 `main.js` 里，按"地图生成 → 渲染 → 玩家 → NPC → 对话 → 结局"排好了段落
- 地形是 `Uint8Array`，`at(x, y)` 取某格地形，`walkable()` 判断能不能走
- 注意一个坑：泥沼必须是"能走进去、进去就出不来"（`walkable` 返回 true），
  不能设成不可通行，否则玩家永远踩不进去，陷泥机制等于失效
- 浏览器控制台里有 `window.__ow.state`，能看到玩家和 NPC 的实时位置，方便调地图
