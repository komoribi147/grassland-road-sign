## 文件

- `manifest.json`：句子 id → 音频文件、说话人、台词、时长。
- `audio/<id>.mp3`：从最初筛选的最终选用音频转成 44.1kHz 单声道 192kbps MP3。

## 怎么对应

网页 `js/engine.js` 在每句台词显示时，用剧情场景 id + 步骤号生成句子 id：

- 普通台词：`场景-步骤号`，例如 `prologue-002`
- 选项回应：`场景-步骤号o选项序号`，例如 `prologue-007o0`
- select 的 after 隐藏台词：`场景-步骤号a`，例如 `act1-017a`

`js/voice.js` 读取 `voice/manifest.json`，只有清单里有的 id 才播放；没有记录的句子静音，不报错。
播放器底部会出现「▶ 回放本句」按钮，浏览器拦截自动播放时点它即可。
