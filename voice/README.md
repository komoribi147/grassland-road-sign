## 对应规则

- 普通台词：场景-三位步骤号，如 prologue-002。
- 选项回应：场景-步骤号o选项序号，如 prologue-007o0。
- 追加对白：场景-步骤号a，如 act1-017a。
- 称呼变体：manifest 条目的 variants 按称呼选择，不改变剧情位置。

manifest.json 包含音频路径、角色、原台词、时长与生成来源。original-recordings.json 固定原 56 句的文件哈希。新增录音标记 generation，包含参考音频、参考转写、seed 和文件校验信息，区别于组员选定的录音。

打开 http://localhost:8790/voice-preview.html 可按四个角色筛选每句；在完整剧情中使用同一套文件。播放器支持静音、音量、取消与回放。自由回复仍在本机实时生成，首次会较慢；不预生成无限数量的自由回复。

详细运行、恢复和检查边界见 docs/VOICE_INTEGRATION.md。
